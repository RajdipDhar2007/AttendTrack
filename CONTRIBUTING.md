# Contributing to AttendTrack

Thanks for helping out! 🎉

## Getting started
1. Fork the repo and clone it.
2. Follow **Build from source** in the [README](README.md) (full JDK + Android SDK).
3. Create a branch: `git checkout -b feature/my-change`.

## Guidelines
- Keep changes focused; one feature or fix per pull request.
- Follow the existing Kotlin / Jetpack Compose style and keep the UI animated and consistent with the current components.
- Test on a real device or emulator (minSdk 26) before opening a PR.
- **Never commit** secrets: `.env`, `local.properties`, keystores, API keys, or heap dumps.
- Write clear commit messages in the imperative ("Add countdown card").

## Pull requests
Describe what changed and why, include screenshots for UI changes, and link related issues.

## Reporting bugs / ideas
Use the issue templates. For security problems, see [SECURITY.md](SECURITY.md) instead.
