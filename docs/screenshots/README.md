## Adding or replacing a screenshot

- Use **lowercase kebab-case names with no spaces** (`my-screen.jpg`). Spaces break image links on GitHub.
- Keep the same file name to replace an image; the README picks it up automatically.
- Add new rows to the table above, and to the main README's gallery if it should be shown there.
- Each image is about 1 MB. Consider compressing new ones (for example with [Squoosh](https://squoosh.app)) to keep the repo and README fast to load.
